# Deterministic routing

1. Explicit production manifest.
2. Existing result/evidence inputs.
3. Standard raw events + raw peptides.
4. Somatic VCF, fusion table, splice table, peptide table, and/or prebuilt SV intermediates.
5. Raw SV VCF may run alone; a mixed raw-SV plus other-source run requires a production manifest or prebuilt SV raw tables.

Multiple non-SV entry branches may be merged into a single standard event/peptide catalogue before the shared evidence layers and rankings are run.
